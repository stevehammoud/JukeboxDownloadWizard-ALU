# Jukebox Download Wizard for ALU

Release downloads and update information for the AtGames Legends version of
Jukebox Download Wizard. This repository does not contain the private JDW
development project or signing key.

Use the versioned installation ZIP from Releases. Read its installation,
hardware support, test and rollback instructions before replacing a working
installation. Cookies and library videos are never included in releases.

The maintainer's current working baseline is 0.1.0-beta.1 single-folder-r2 on
HA8801/RK3328. The 0.1.0-beta.2 embedded-UCE candidate requires a new device
test and will remain a draft until that test passes. Other models remain
experimental/unverified. No universal hardware-support claim is made.

Automatic ALU update integration is planned. Prepared metadata alone does
not add an updater to existing installations. See UPDATE-FORMAT.md.

Third-party runtime notices accompany the binaries inside the UCE.
